## Caso de estudio: de Vanilla JS a React

Este caso de estudio muestra un salto de madurez técnica: pasar de manipular manualmente el DOM y duplicar lógica entre páginas a trabajar con una arquitectura modular, reutilizable y más predecible.

El objetivo fue separar responsabilidades entre datos, negocio y presentación, mejorar la mantenibilidad y preparar la interfaz para crecer con mayor claridad.

- Componentes reutilizables para buscador, filtros, tarjetas y detalle.
- Flujo de datos más predecible y estado centralizado.
- Módulos dedicados para consumo de APIs y lógica de interfaz.
- Menor duplicación funcional y mejor escalabilidad del frontend.

## Qué puedo aportar

- **Desarrollo frontend:** interfaces responsivas, accesibles y con interacciones claras usando JavaScript y React.
- **Backend y APIs:** servicios con Express, autenticación JWT y gestión de datos con PostgreSQL.
- **UX/UI y producto:** diseño centrado en el usuario, coherencia visual y comunicación de la propuesta de valor.
- **Visión de negocio:** capacidad para conectar objetivos comerciales, necesidades de usuario y decisiones técnicas.

## Estructura multimedia

```text
assets/
├── images/    # Capturas optimizadas de los proyectos en formato JPEG
└── videos/    # Video del hero en WebM y MP4
```

Las imágenes del landing utilizan carga diferida (`loading="lazy"`) y decodificación asíncrona para reducir el trabajo inicial del navegador. El video utiliza `preload="metadata"` y cuenta con MP4 como alternativa de compatibilidad.

## Ejecutar el proyecto

Este es un sitio estático. Puede abrirse directamente desde `index.html` o servirse localmente con cualquier servidor HTTP estático.

```bash
npx serve .
```

Después, abre la URL indicada por el servidor para visualizar el portafolio.
