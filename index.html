Acto III — La transformación

De Vanilla JS a React

Un salto de madurez técnica: pasar de manipular manualmente el DOM y duplicar lógica entre páginas, hacia una arquitectura modular, reutilizable y más predecible.

Repensando la arquitectura frontend

El mayor desafío técnico no fue consumir la API, sino cambiar la forma de pensar la interfaz. En Alky Wallet, cada vista llevaba su propia lógica y duplicación; en React, el proyecto se estructuró como un sistema de componentes reutilizables con estado centralizado y una lógica mucho más clara.

El objetivo fue separar responsabilidades entre datos, negocio y presentación, aplicando buenas prácticas de organización de código y mejorando la escalabilidad del proyecto.

  • Enfoque de componentes: buscador, filtros, tarjetas y detalle de producto.
  • Estado más predecible: flujo unidireccional y datos centralizados.
  • Mejor mantenibilidad: módulos dedicados para consumo de APIs y lógica de UI.
